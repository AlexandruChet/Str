# Документация для проекта "Mój-dom"
# index.html

## Обзор
Этот проект представляет собой веб-сайт для компании "Mój-dom", которая специализируется на ремонте и строительных услугах. Веб-сайт разработан для демонстрации услуг, предоставления контактной информации и подчеркивания профессионализма компании в области строительства и дизайна.

---

## Структура файлов

### HTML
Основной файл HTML `index.html` содержит структуру веб-сайта и ссылки на внешние ресурсы, такие как стили, изображения и скрипты.

### CSS
- `/project/src/components/css/reset.css`: Сбрасывает стили браузера для единообразия.
- `/project/src/components/css/style.css`: Содержит пользовательские стили для веб-сайта.

### JavaScript
- `/project/src/components/js/app.js`: Файл скриптов для добавления интерактивности (на данный момент реализация отсутствует).

### Ресурсы
- `/project/src/assets/icons/`: Содержит иконки, такие как логотип компании.
- `/project/src/assets/img/`: Содержит изображения, используемые на сайте.

## Функционал

### Хедер и навигация
- **Навигационная панель**:
  - Включает ссылки на разные разделы сайта:
    - `Materiale`
    - `Interior`
    - `Despre companie`
  - Добавлена кнопка "бургер-меню" (`id="burger-menu"`) для адаптивного дизайна.

### Основные секции контента
#### Секция 1: Введение
- Подчеркивает миссию и услуги компании.
- Включает заголовок, описательный текст и кнопку (`id="btnBlock"`).

#### Секция 2: Подробности об услугах
- Описывает процесс подготовки стен к покраске.

#### Секция 3: О компании
- Содержит статью о специализации компании на ремонтах.
- Подсекции:
  - Обзор услуг компании.
  - Подробное описание её истории и ценностей.

#### Секция 4: Строительные услуги
- Предоставляет обзор строительных услуг, включая проектирование, ремонт и техническое обслуживание зданий.
- Включает ссылку с призывом к действию для получения дополнительной информации.

#### Секция 5: Электромонтажные работы
- Краткое введение в услуги, связанные с электромонтажом, дополненное изображением и текстом-заполнителем.

#### Секция 6: Услуги по укладке плитки
- Подчеркивает преимущества использования текста-заполнителя "Lorem ipsum" в дизайне.
- Включает кнопку для получения дополнительной информации.

#### Секция 7: Сантехнические работы
- Описывает профессиональные услуги по установке канализации.
- Акцент на надежность и соблюдение строительных стандартов.
